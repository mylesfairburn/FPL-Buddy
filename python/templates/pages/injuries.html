How to read this

A percentage is Fantasy Premier League's own chance-of-playing figure for the next gameweek, and it only appears when the game publishes one. A flagged player with no percentage is flagged without a number attached — usually a fresh injury, occasionally a suspension where the return date is already known.

Predicted points across the site already account for this: a player unlikely to start is projected accordingly, so a flagged player's numbers on the ratings table are not the numbers he would carry if fit. The my team page flags anyone in your own squad, and the FAQ covers what the projections do and don't try to predict.
